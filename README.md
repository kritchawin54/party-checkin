# งานเลี้ยง ปาร์ตี้ หน้ากากทักซิโด ยินดีตำแหน่งใหม่ รองด้วง ใหญ่กว่าเดิม

เว็บแอปให้แขกสแกน QR แล้วกรอกชื่อเพื่อร่วมงาน ใช้ได้จากมือถือทุกเครือข่าย ไม่ต้องต่อ Wi‑Fi เดียวกับเจ้าหน้าที่

## เปิดให้ทุกคนเข้าได้ (แนะนำวันงาน)

คอมพิวเตอร์เจ้าหน้าที่เปิดค้างไว้ แล้วรัน 2 คำสั่ง:

```bash
npm install
npm run dev
```

อีกหน้าต่างหนึ่ง:

```bash
npm run public
```

จะได้ลิงก์แบบ `https://....trycloudflare.com`  
เปิดลิงก์นั้นบนมือถือหรือจอเจ้าหน้าที่ หน้าแรกจะเป็น QR ให้แขกสแกนด้วยเน็ตมือถือได้เลย

## ขึ้นเว็บถาวร

1. `npm run build`
2. ฝากที่ Render / Railway / โฮสต์ Node แล้วสั่ง `node server.mjs`
3. วางลิงก์เว็บในช่อง **ลิงก์สาธารณะ** ที่หน้าภาพรวม
